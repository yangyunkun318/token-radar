How each implied value is built

implied = TVL × category multiple × growth × maturity

  • Category multiple. For each category, the median market-cap / TVL of the protocols in that category that already trade, taken from this same snapshot. A category with fewer than 4 traded names falls back to the whole market's median. Multiples are clamped to 0.05 – 1.00.
  • Growth. The protocol's 7-day TVL change, clamped to −60% … +120%, at half weight: 1 + growth × 0.5.
  • Maturity. 0.60 + min(age, 1095 days) / 1095 × 0.40. A protocol with no listing date is scored as 365 days old.
  • Rank. Rows sort by implied value, highest first. The watchlist is the floor, never the ceiling: the board ranks every rankable pre-token protocol the snapshot holds, 40 on the watchlist and the rest below it. Rankable means it records no token and is not a wrapped, staked or bridged product of a token that already trades — the same rule the watchlist itself uses — and not a versioned pool or an exchange.

“Records no token” is DefiLlama's record, not proof: a protocol on the list may still have a token its record does not carry. An implied value is this radar's own claim, never a prediction that a token is issued, or when.
